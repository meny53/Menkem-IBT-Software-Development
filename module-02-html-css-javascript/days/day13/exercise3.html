CSS Specificity Example

This paragraph is targeted by an element selector, a class selector and an ID selector.

Explanation

  • Element selector (p) → Specificity: 0-0-1
  • Class selector (.important) → Specificity: 0-1-0
  • ID selector (#special) → Specificity: 1-0-0

Winner: The ID selector (#special) because it has the highest specificity score.
